# 🎯 Quiz App

An interactive, timed multiple-choice Quiz App built using **HTML, CSS, and JavaScript** — all in a single file. No frameworks, no dependencies, just vanilla web tech.

## 🚀 Live Demo

[View Live App](#) <!-- Apna GitHub Pages link yahan paste kar dena -->

## ✨ Features

- ❓ 10 multiple-choice questions
- ⏱️ Timer for each question (auto-advances when time runs out)
- ✅ Instant feedback on answer selection (correct/incorrect highlight)
- 📊 Progress bar / "Question X of 10" counter
- 🏆 Final score with percentage
- 💬 Motivational message based on performance
- 🔄 Restart Quiz option
- 🎨 Clean, modern, card-based UI with gradient background
- 📱 Fully responsive design
- ✨ Smooth animations and hover effects

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📂 Project Structure

```
quiz-app/
└── index.html   # Contains all HTML, CSS, and JS in one file
```

## 💻 How to Use

1. Clone or download this repository
2. Open `index.html` in any web browser
3. Start the quiz and test your knowledge!

```bash
git clone https://github.com/TejasMohitkar001/quiz-app.git
```
